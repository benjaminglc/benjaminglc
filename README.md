#  Hello World 🦦

I'm Benjamin. I research digital twins at UAP's Research Center Hagenberg, study Mobile Computing, and build iOS apps and small tools on the side.\
I've been creating bugs since 2016.

### Stuff I've been working on

- **Digital twin & simulation engine** (research, ongoing): a graph-based digital twin and simulation engine for EV charging infrastructure. Also the topic of my Master's thesis.
- **SpotHopper** (Bachelor's thesis): an iOS venue recommender with the full ML pipeline from training in TensorFlow to on-device inference with TFLite, deployed via Firebase ML.
- **Pokédex**: an iOS app that recognizes real Pokémon figures through the camera, using a classifier trained only on game sprites. I built the ML pipeline (sim-to-real transfer learning with MobileNetV2) and the app with on-device Core ML inference; 69% accuracy on real photos without a single real photo in training.
- **RGBle**: a color-guessing game with multiplayer, built natively for iOS from scratch and shipped on the App Store. A ground-up rewrite (current APIs, cleaner architecture, better performance) is planned.
- **Small tools**: utilities that fix my own annoyances, like BusySignal, a native macOS menu bar app that shows which processes hold which ports and finds free ones. Linux tools are next, since Linux joined my setup.
